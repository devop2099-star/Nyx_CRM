CRM.ApiHub (.NET 8) (.NET 8 Web API)
Activo
Capa & Tipo de Componente
Backend / Núcleo Hexagonal
Contenedor & Puerto de Red
Container: crm_api | Kestrel Server (Port: 5000)
Descripción Funcional
Servidor REST de alta concurrencia basado en Clean Architecture y CQRS. Gestiona tokens JWT HS256, validación de reglas comerciales y WebSocket Hubs.
Código C# / Configuración
[HttpPost("leads")] [Authorize(Roles = "Asesor,Supervisor")] public async Task CreateLead([FromBody] CreateLeadDto dto) { var result = await _mediator.Send(new CreateLeadCommand(dto)); return CreatedAtAction(nameof(GetById), new { id = result.Id }, result); }
