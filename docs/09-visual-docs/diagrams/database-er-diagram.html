crm.leads
PostgreSQL 16
Esquema & Clave Primaria
Esquema: crm | PK: id (UUID)
Descripción Funcional
Prospectos comerciales. Valida cédula ecuatoriana (módulo 10), detecta duplicados en los últimos 30 días y almacena respuestas del cuestionario dinámico en JSONB.
Sentencia DDL (PostgreSQL)
CREATE TABLE crm.leads ( id UUID PRIMARY KEY DEFAULT gen_random_uuid(), document_number VARCHAR(20) NOT NULL, first_name VARCHAR(100) NOT NULL, last_name VARCHAR(100) NOT NULL, phone VARCHAR(20) NOT NULL, status VARCHAR(50) NOT NULL, assigned_advisor_id UUID REFERENCES auth.users(id), qualification_json JSONB, created_at TIMESTAMPTZ DEFAULT NOW() );
Índices & Constraints
CREATE INDEX idx_leads_doc ON crm.leads(document_number); CREATE INDEX idx_leads_advisor_status ON crm.leads(assigned_advisor_id, status);
