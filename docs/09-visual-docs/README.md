# 09 — Visual Documentation (Documentación Visual)

## Propósito
Esta carpeta contiene activos visuales, diagramas interactivos, mockups de pantallas UI del frontend Blazor (`CRM.WebFrontend`) y walkthroughs paso a paso.

---

## Estructura

```text
09-visual-docs/
├── mockups/          <-- Diseños y capturas de pantallas UI (Asesor, Supervisor, Backoffice)
├── walkthroughs/      <-- Guías visuales interactivas y flujos paso a paso (.html)
└── diagrams/         <-- Diagramas exportados (.png, .svg, .drawio)
```

---

## Contenido

- **`mockups/`**: Contiene mockups de pantallas de Blazor (`AsesorDashboard`, `AudioAudit`, `BackofficeActivations`).
- **`walkthroughs/`**: Contiene recorridos visuales en HTML interactivo para onboarding de nuevos usuarios y validación funcional.
- **`diagrams/`**: Diagramas de componentes, datos y despliegue del CRM.
