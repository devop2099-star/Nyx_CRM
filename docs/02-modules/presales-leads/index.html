Módulo de Pre-Ventas & Gestión de Leads

Especificación técnica exhaustiva del ciclo de vida comercial: captura, validación algorítmica de identificación, detección de duplicidad temporal, cuestionarios dinámicos de elegibilidad y transición a órdenes de venta.

1. Propósito & Responsabilidades de Dominio

El módulo PreSales / Leads constituye la puerta de entrada comercial para el Call Center. Gestiona el ciclo prospectivo completo, garantizando que ninguna venta se formalice sin antes cumplir los requisitos jurídicos (Cédula/DNI válida), técnicos (Cercanía a caja NAP) y comerciales (Cero duplicidad y no deudor en ERP legacy).

Captura & Validación Inmediata

Recepción de prospectos vía API REST o formulario UI (Ctrl + Alt + N). Ejecución en tiempo real del algoritmo Módulo 10 de dígito verificador y sanitización telefónica (10 dígitos exactos).

Motor Anti-Duplicados (Ventana 30 Días)

Comprobación estricta de concurrencia en PostgreSQL: si la cédula o teléfono fueron ingresados en los últimos 30 días, el sistema enlaza el prospecto a la orden previa e inhabilita comisiones dobles.

Cuestionarios Dinámicos de Calificación

Motor de evaluación basado en esquemas JSON polimórficos almacenados en crm.leads.qualification_json (JSONB) para validar factibilidad técnica y solvencia.

Asignación & Cron de Rebalanceo

Asignación equitativa (Round-Robin) entre asesores comerciales con turno activo. Cron background que redistribuye prospectos sin gestión tras 60 minutos.

3. Algoritmo de Validación: Dígito Verificador (Módulo 10)

Implementación en el Value Object DniDocument.cs en la capa de Dominio C#.

namespace CRM.Domain.ValueObjects; public sealed class DniDocument : ValueObject { public string Value { get; } private DniDocument(string value) => Value = value; public static Result<DniDocument> Create(string rawDni) { if (string.IsNullOrWhiteSpace(rawDni)) return Result.Failure<DniDocument>("La cédula no puede estar vacía."); var clean = rawDni.Trim().Replace("-", ""); if (clean.Length != 10 || !clean.All(char.IsDigit)) return Result.Failure<DniDocument>("La cédula debe contener exactamente 10 dígitos numéricos."); int provincia = int.Parse(clean.Substring(0, 2)); if (provincia < 1 || provincia > 24) return Result.Failure<DniDocument>("Código de provincia inválido."); int tercerDigito = int.Parse(clean[2].ToString()); if (tercerDigito >= 6) return Result.Failure<DniDocument>("El tercer dígito de persona natural debe ser menor a 6."); // Algoritmo Módulo 10 con coeficientes [2, 1, 2, 1, 2, 1, 2, 1, 2] int[] coeficientes = { 2, 1, 2, 1, 2, 1, 2, 1, 2 }; int suma = 0; for (int i = 0; i < 9; i++) { int valor = int.Parse(clean[i].ToString()) * coeficientes[i]; suma += (valor >= 10) ? (valor - 9) : valor; } int digitoVerificadorEsperado = (suma % 10 == 0) ? 0 : (10 - (suma % 10)); int digitoVerificadorReal = int.Parse(clean[9].ToString()); if (digitoVerificadorEsperado != digitoVerificadorReal) return Result.Failure<DniDocument>("Dígito verificador de cédula incorrecto."); return Result.Success(new DniDocument(clean)); } }

4. Detección Anti-Duplicados: Query SQL & Regla de Negocio

Regla Operativa: Si un prospecto con el mismo número de cédula o teléfono ingresa al sistema dentro de una ventana de 30 días continuos respecto a una orden en curso, la creación no genera un nuevo lead comisionable, sino que retorna código HTTP 409 Conflict enlazando la referencia original.
-- Comprobación ejecutada por LeadRepository.cs antes de insertar SELECT l.id AS original_lead_id, l.assigned_advisor_id, l.status, l.created_at, u.username AS advisor_username FROM crm.leads l JOIN auth.users u ON u.id = l.assigned_advisor_id WHERE (l.document_number = @DocumentNumber OR l.phone = @PhoneNumber) AND l.created_at >= NOW() - INTERVAL '30 days' AND l.status NOT IN ('Disqualified') LIMIT 1;

7. Definición DDL en Base de Datos (PostgreSQL 16)

CREATE TABLE crm.leads ( id UUID PRIMARY KEY DEFAULT gen_random_uuid(), document_number VARCHAR(20) NOT NULL, document_type VARCHAR(10) NOT NULL DEFAULT 'DNI', first_name VARCHAR(100) NOT NULL, last_name VARCHAR(100) NOT NULL, phone VARCHAR(20) NOT NULL, email VARCHAR(150), city VARCHAR(100) NOT NULL, address TEXT NOT NULL, offered_plan_id VARCHAR(50), campaign_source VARCHAR(100), status VARCHAR(50) NOT NULL DEFAULT 'New', assigned_advisor_id UUID REFERENCES auth.users(id), qualification_json JSONB, created_at TIMESTAMPTZ NOT NULL DEFAULT NOW(), updated_at TIMESTAMPTZ NOT NULL DEFAULT NOW(), CONSTRAINT chk_lead_status CHECK ( status IN ('New', 'InContact', 'Qualified', 'Disqualified', 'SalesOrderCreated', 'Duplicate') ) ); -- Índices B-Tree para optimización de consultas de alta concurrencia CREATE INDEX idx_leads_doc_created ON crm.leads(document_number, created_at DESC); CREATE INDEX idx_leads_phone_created ON crm.leads(phone, created_at DESC); CREATE INDEX idx_leads_advisor_status ON crm.leads(assigned_advisor_id, status); CREATE INDEX idx_leads_qualification_gin ON crm.leads USING GIN (qualification_json);

8. Orquestación CQRS (MediatR Command Handler en C#)

public sealed class CreateLeadCommandHandler : IRequestHandler<CreateLeadCommand, Result<LeadResponseDto>> { private readonly ILeadRepository _leadRepository; private readonly IUnitOfWork _unitOfWork; private readonly ICurrentUserService _currentUser; private readonly ILogger<CreateLeadCommandHandler> _logger; public CreateLeadCommandHandler( ILeadRepository leadRepository, IUnitOfWork unitOfWork, ICurrentUserService currentUser, ILogger<CreateLeadCommandHandler> logger) { _leadRepository = leadRepository; _unitOfWork = unitOfWork; _currentUser = currentUser; _logger = logger; } public async Task<Result<LeadResponseDto>> Handle(CreateLeadCommand request, CancellationToken ct) { // 1. Validar Value Object DniDocument (Módulo 10) var dniResult = DniDocument.Create(request.DocumentNumber); if (dniResult.IsFailure) return Result.Failure<LeadResponseDto>(dniResult.Error); // 2. Comprobar ventana anti-duplicados (30 días) var duplicate = await _leadRepository.FindDuplicateAsync(dniResult.Value.Value, request.Phone, ct); if (duplicate != null) { _logger.LogWarning("Lead duplicado detectado para DNI {Dni}. Lead Original: {Id}", request.DocumentNumber, duplicate.Id); return Result.Failure<LeadResponseDto>(LeadErrors.DuplicateWithinWindow(duplicate.Id, duplicate.CreatedAt)); } // 3. Crear Entidad de Dominio var lead = Lead.Create( dni: dniResult.Value, firstName: request.FirstName, lastName: request.LastName, phone: request.Phone, email: request.Email, city: request.City, address: request.Address, offeredPlanId: request.OfferedPlanId, campaignSource: request.CampaignSource, assignedAdvisorId: _currentUser.UserId ); await _leadRepository.AddAsync(lead, ct); await _unitOfWork.SaveChangesAsync(ct); _logger.LogInformation("Lead {Id} creado exitosamente por asesor {User}", lead.Id, _currentUser.Username); return Result.Success(lead.ToDto()); } }
