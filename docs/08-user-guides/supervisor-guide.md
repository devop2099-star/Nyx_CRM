# Guía de Usuario — Rol Supervisor de Operaciones

## Objetivo
Guiar al Supervisor en el proceso de auditoría de grabaciones de llamadas, validación de datos de pre-venta y aprobación de órdenes hacia Backoffice.

## Procedimiento de Auditoría
1. **Acceso a la Bandeja**:
   - Ingresar a la opción **Auditoría de Audio** (`AudioAudit.razor`).
2. **Reproducción de Evidencias**:
   - Escuchar la grabación adjunta utilizando el reproductor de audio integrado.
3. **Verificación de Checklists**:
   - Marcar la casilla de verificación para cada punto normativo (Lectura de contrato, Aceptación de tarifa, Confirmación de cédula).
4. **Dictamen**:
   - **Aprobar**: La solicitud avanza a Backoffice.
   - **Rechazar / Devolver**: Seleccionar el motivo y presionar `Devolver a Asesor`.
