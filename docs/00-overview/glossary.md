# Glosario de Términos

| Término | Definición |
|---|---|
| **Lead (Prospecto)** | Contacto potencial que ha mostrado interés o cumple con el perfil para adquirir un servicio. |
| **Órden de Venta (Sales Order)** | Documento formal que registra la intención de compra del cliente y que debe pasar por el proceso de activación. |
| **Backoffice** | Equipo encargado de verificar, validar y procesar operativamente las ventas realizadas por los asesores. |
| **FDW (Foreign Data Wrapper)** | Extensión de PostgreSQL utilizada para acceder a tablas de bases de datos remotas como si fueran locales. |
| **AHT (Average Handling Time)** | Tiempo promedio de operación/atención por cada llamada o gestión. |
| **GLPI** | Herramienta de gestión de servicios de TI utilizada para el manejo interno de tickets de soporte técnico. |
| **JWT (JSON Web Token)** | Estándar utilizado para transmitir de forma segura la identidad y permisos del usuario autenticado. |
