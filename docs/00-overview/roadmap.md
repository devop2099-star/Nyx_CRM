# Roadmap del Proyecto

## Q1 - MVP Core
- ✅ Autenticación JWT y sistema de roles base.
- ✅ Módulo de Pre-venta (gestión de leads).
- ✅ Módulo de Ventas (creación de órdenes).
- ✅ Integración con bases de datos legacy mediante FDW.

## Q2 - Expansión Operativa
- ✅ Flujo completo de Backoffice para activaciones.
- ✅ Módulo de Supervisión y Auditoría.
- ✅ Dashboards operativos básicos.
- 🚧 Integración con SMTP para notificaciones por email.

## Q3 - Madurez y Automatización
- 📅 Módulo de Comisiones automatizado (reglas dinámicas).
- 📅 Integración completa bidireccional con GLPI.
- 📅 Sistema de reportes gerenciales avanzados (exportación Excel/PDF).

## Q4 - Futuro
- 📅 Soporte para multicanalidad (WhatsApp, Redes Sociales integradas).
- 📅 Módulo de gamificación para asesores.
- 📅 Implementación de Cache Distribuido (Redis) para alta concurrencia.
