# Alcance (Scope)

## Qué INCLUYE el sistema (En alcance)
- **Gestión de Usuarios**: Autenticación, roles y permisos (Asesor, Supervisor, Backoffice, Admin).
- **Módulo de Pre-venta**: Administración de leads y asignación de prospectos.
- **Módulo de Ventas**: Creación, seguimiento y cierre de órdenes de venta.
- **Módulo de Backoffice**: Flujo de validación y activación técnica de servicios vendidos.
- **Módulo de Comisiones**: Cálculo automatizado de comisiones según las reglas de negocio vigentes.
- **Módulo de Auditoría**: Herramientas para que el supervisor controle la calidad del trabajo.
- **Integraciones**: Integración con PostgreSQL legacy (FDW) y GLPI para incidencias.

## Qué NO INCLUYE el sistema (Fuera de alcance)
- **Telefonía IP/PBX**: El CRM no actúa como un softphone ni gestiona las llamadas telefónicas directamente.
- **Facturación Electrónica**: No genera facturas fiscales hacia los clientes finales (este proceso recae en el ERP externo).
- **Manejo de Nómina**: El cálculo de comisiones es solo un insumo, el pago de planillas salariales se realiza en un sistema de RRHH.
