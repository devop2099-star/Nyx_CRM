# Release v1.0.0 — Versión Inicial CRM Call Center

## Fecha de Lanzamiento
2026-08-06

## Novedades Principales
- **Backend (`CRM.ApiHub`)**:
  - Arquitectura Hexagonal con .NET 8 Web API.
  - Autenticación segura mediante JWT y Refresh Tokens.
  - Integración FDW con base de datos legacy PostgreSQL.
  - Endpoints de PreVentas, Órdenes, Auditoría, Activaciones, Comisiones e Incidentes.
- **Frontend (`CRM.WebFrontend`)**:
  - Interfaz interactiva Blazor para Asesores, Supervisores y Backoffice.
  - Reproductor de auditoría de audios e historial de llamadas.
  - Tableros de control e indicadores operativos.
- **Documentación**:
  - Estructuración documental estandarizada completa en `docs/`.
